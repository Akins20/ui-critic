# uicritic

`npx uicritic` runs [`@akins20/ui-critic`](https://www.npmjs.com/package/@akins20/ui-critic),
a second pair of eyes on a UI: capture a site or an app, get a ranked critique from
Gemini or OpenAI against your product's brief, and verify changes before and after.

The unscoped name `ui-critic` on npm is a different tool, so `npx ui-critic` does not
run this one. Use `npx uicritic`, `npx @akins20/ui-critic`, or install it with
`npm i -g @akins20/ui-critic`, which provides both the `ui-critic` and `uicritic`
commands.

Documentation: https://github.com/Akins20/ui-critic#readme
